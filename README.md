# MY SKIN WEATHER · 오늘의 피부 날씨

SKT ALEPH 과제 **오늘의 진짜 정보판 — 데이터가 안 올 때**를 위한 독립 프로젝트입니다. 공개 기상 API에서 상대습도를 가져와 Asia/Seoul 기준 하루 한 건을 남기고, 어제와 비교합니다. 조회에 실패하면 마지막 정상값과 그 시각, 실패 이유, 다음 행동을 표시합니다.

**현재 단계** · 도시별 기상 정보판과 브라우저 전용 스킨케어 기능을 구현했습니다. 대전의 공개 검증 기록 두 건을 보존했습니다. 공식 fixture 검증은 자료 확보 후 진행합니다.

## 로컬 실행

Mac에서는 프로젝트 폴더의 `실행.command`를 열면 로컬 서버와 브라우저가 시작됩니다. 새로 열린 터미널을 켜 두면 계속 사용할 수 있습니다. `dist/index.html`을 파일로 직접 열면 실행 중인 로컬 앱으로 이동을 시도하고, 실행 안내와 화장대 링크를 제공해요.

프로젝트 폴더에서 아래 명령을 실행한 뒤 [로컬 정보판](http://127.0.0.1:8000/)을 엽니다. Python 3과 인터넷 연결이 필요합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

페이지를 열거나 **날씨 조회**를 누르면 선택한 도시의 고정 공개 좌표로 Open-Meteo에 요청합니다. 기본은 대전입니다. 정상 기록은 도시별로 KST 하루 한 건씩 저장됩니다. 실패 후에는 **다시 시도**를 누를 수 있습니다. 화면의 원천 시각은 Open-Meteo 모델 데이터의 유효 시각입니다.

- [REQUIREMENTS.md](REQUIREMENTS.md) · 과제 기준과 검증 증거
- [PLAN.md](PLAN.md) · 진행 체크리스트와 다음 작업
- [AGENTS.md](AGENTS.md) · 이어서 작업할 때 적용할 규칙

## 화면 범위

- **공개 정보판** · 오늘의 상대습도(%), 어제 대비(%p), 출처 이름과 실제 원천 URL, 원천시각, 조회시각, 기준 시간대(Asia/Seoul), 일별 기록, 실패 및 복구 상태.
- **내 피부와 화장대** · 민감도·건조함·유분감·붉은기를 저장하고 이전 입력과 비교합니다. 화장대 제품을 등록·수정·삭제할 수 있고, 그중 날씨와 피부 입력에 맞는 제품을 이유와 함께 표시합니다. 개인 기록은 사이트 주소별 브라우저 저장소에만 남습니다.
- **기능성 제품 집중 관리** · 제품별 마지막 실제 사용일과 설정한 간격으로 다음 주기 확인일을 표시합니다. 확인일은 제품 안내와 피부 반응을 함께 살펴볼 때 참고하는 날짜입니다. 주 2회·3회 설정에서는 최근 7일 사용 횟수를, 사용 보류 상태에서는 보류 안내를 표시합니다.
- **전성분 분석** · 한글 성분명과 일부 INCI 명칭을 기기에서 대조합니다. 확인한 성분명을 제품 카드에 표시하고, 수분 공급·보습·진정 후보와 민감한 날 주의할 후보를 구분하는 데 참고합니다. 농도와 제품 자체의 효과 및 개인별 자극 여부는 별도의 정보가 필요합니다.
- **공개 검증 기록** · 대전의 실제 원자료와 정규화 결과를 `dist/evidence/`에 별도로 보존합니다. 공개 화면에서 2026년 11월 4일과 5일의 대전 습도 및 어제 대비 변화를 확인할 수 있습니다.

## 공개 결과물

[MY SKIN WEATHER 열기](https://wjddncjf.github.io/my-skin-weather/)

1. 사이트에서 **오늘의 피부 날씨**를 엽니다.
2. 정상 조회 시 상대습도와 단위가 표시됩니다. 조회가 실패하면 오류 이유와 다시 시도 버튼이 표시되며, 마지막 정상값이 있다면 오래된 값으로 표시됩니다.
3. **나의 기록 → 공개 검증 기록**에서 대전 기록 두 건과 어제 대비 변화량을 확인할 수 있습니다.

GitHub Actions는 `dist/`를 GitHub Pages에 게시합니다. 피부 상태와 화장대 기록은 브라우저에 저장됩니다.
